# Vision

`mac-os-agent` is the place on this Mac to start just about anything.
Where a thing gets finished depends on the thing.

It answers three kinds of request from one text field.
When the owner knows what they want, they get it nearly instantly.
When they know there is a thing but not its details, the agent finds it promptly and, where it is safe to, does it for them.
When they have a question or want to think out loud, the agent indulges them.

It is built for quick hits, not for deep analysis or long-running work.
When a request outgrows a quick hit, the agent hands it on to a tool made for that, with what it already knows.
It does not rule out any way the owner wants to extend it, and it is tuned for the quick hit.

A change aligns when it makes one of the three faster or more certain without slowing the other two.
A change should be resisted when it turns the agent into the place work gets finished, or makes the first kind of request wait.
