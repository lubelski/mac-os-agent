# Planning

What has been decided for mac-os-agent, what is planned, and ideas to try later. The repo's `README.md` says what the app is and how to run it.

- [decided.md](decided.md): what is settled and built, and how each part behaves.
- [planned.md](planned.md): what is proposed and not yet agreed, what is still open, and what has not been started.
- [ideas.md](ideas.md): experiments the owner has raised. None is a plan.
- [panel-with-input-pill.md](panel-with-input-pill.md): one proposal big enough for a file of its own, a redesign of the panel. `planned.md` points to it.

When a decision changes, move it between these files, and between the lists in `planned.md`, in the same pull request.
